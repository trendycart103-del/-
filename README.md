# 🚜 গাড়ীর হিসাব (হাজিরা ও হিসাব)

গাড়ির ট্রিপ, হাজিরা আর হিসাবের একটা অফলাইন অ্যান্ড্রয়েড অ্যাপ।
পুরো অ্যাপটা একটাই HTML ফাইলে লেখা, আর অ্যান্ড্রয়েড অংশটা শুধু সেটাকে ফুল-স্ক্রিনে দেখায় (WebView)।

- Package: `com.example.triperhisab`
- ডাটা ফোনেই থাকে (localStorage), ইন্টারনেট লাগে না
- স্ক্রিন: পোর্ট্রেট

## ফোল্ডার কোথায় কী

| পথ | কাজ |
|---|---|
| `app/src/main/assets/www/index.html` | **আসল অ্যাপ**: ডিজাইন, হিসাব, সব এখানে। বদলাতে চাইলে এই ফাইলটাই এডিট করুন |
| `app/src/main/assets/bridge.js` | ব্যাকআপ ডাউনলোড যেন অ্যান্ড্রয়েডে কাজ করে তার ছোট স্ক্রিপ্ট |
| `app/src/main/java/.../MainActivity.kt` | WebView চালু করে, ফাইল সিলেক্ট/সেভ ও confirm ডায়ালগ সামলায় |
| `app/src/main/res/` | আইকন, অ্যাপের নাম, থিম |
| `.github/workflows/build-apk.yml` | গিটহাব নিজে APK বানানোর নির্দেশ |
| `docs/original-app-config.json` | আগের APK-র কনফিগ (রেফারেন্স) |

## গিটহাব থেকে APK বানানোর নিয়ম

1. গিটহাবে নতুন একটা রিপোজিটরি খুলুন।
2. এই জিপের ভেতরের **সব ফাইল** (`.github` ফোল্ডারসহ) রিপোজিটরির `main` ব্র্যাঞ্চে আপলোড/পুশ করুন।
3. রিপোজিটরির **Actions** ট্যাবে যান, **Build APK** চলতে শুরু করবে (না চললে **Run workflow** চাপুন)।
4. সবুজ টিক এলে ওই রান খুলে নিচে **Artifacts** থেকে `triperhisab-debug-apk` নামিয়ে নিন, ভেতরে `app-debug.apk` আছে।

Android Studio-তে বানাতে চাইলে ফোল্ডারটা Open করুন, Gradle Sync শেষ হলে **Build → Build APK(s)**।

## ⚠️ পুরোনো অ্যাপ থেকে নতুনে যাওয়ার আগে অবশ্যই পড়ুন

নতুন APK আলাদা সাইনিং কী দিয়ে তৈরি হয়, তাই পুরোনো অ্যাপের ওপর আপডেট হবে না। পুরোনোটা **আনইনস্টল** করতে হবে, আর আনইনস্টল করলে অ্যাপের ভেতরের সব ডাটা মুছে যাবে।

তাই আগে পুরোনো অ্যাপ থেকে **JSON ব্যাকআপ** ডাউনলোড করে সেভ রাখুন, নতুন অ্যাপ ইনস্টল করে "আগের JSON ব্যাকআপ ফিরিয়ে আনুন" দিয়ে ফেরত আনুন।

## নোট

- GitHub Actions থেকে যে APK পাবেন সেটা **debug** সাইনড, ফোনে ইনস্টল করা যায়। Play Store-এ দিতে চাইলে নিজের কীস্টোর দিয়ে release বিল্ড করতে হবে।
- পুরোনো APK-তে AdMob লাইব্রেরি ছিল, কিন্তু কনফিগে বন্ধ ছিল আর কোনো বিজ্ঞাপন আইডি ছিল না। নতুন প্রজেক্টে ওটা রাখা হয়নি।
